# 汽车主机厂财报跟踪

线上页面：<https://clongking.github.io/oem-earnings-tracker/>

首页是月历，只标已经核对的发布日。

仓库：<https://github.com/clongking/oem-earnings-tracker>。Pages 从 `main` 分支的根目录发布。

检索日 **2026-10-18**。只收上市整车厂，不含一级供应商和经销商。

网页把四类材料分开列：

- 官方链接：公司新闻稿、IR 日历、交易所或监管归档页面
- 财报 PDF：公司或交易所 PDF
- 文字记录：公司自己的问答或带 transcript 的讲稿
- 视频：公司托管的业绩会或公司视频

「半年跟踪」收到 **2027-04-18**。每家只写已经公布的下一场；没有公布的写「未公布」。核对项来自上一份已打开的公司或交易所原文，用来对照下一场，不是卖方一致预期，也不补未公布的收入或每股收益。勾选和笔记只存在浏览器本地。

名录、日期冲突和覆盖缺口见 [docs/oem-earnings-tracker.md](docs/oem-earnings-tracker.md)。

数字和日期只反映检索日打开来源时的内容。A 股预约披露会改期。

## 本地打开

用浏览器打开 `index.html`。数据写在页面里，不需要服务器。
